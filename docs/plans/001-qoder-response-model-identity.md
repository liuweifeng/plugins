# Qoder 两站请求时模型名称

关联 issue：#412。

## 目标与范围
为 qoder 与 qoder-cn 全部模型保留请求时的供应商显示名称，保持路由 ID、账号和模型配置兼容。QwenWork 系列不在此次范围内。

## 决策
- 每次请求刷新账号模型列表，按原 key 获取非空显示名称，供 JSON/SSE 响应使用。
- 显示名称不用于模型列表键或上游路由，因此同名槽位仍分别可选。
- 刷新失败或名称为空时回退原请求 ID，不使用缓存旧名称声明当前版本；正常请求仍可使用已有缓存继续。
- 名称是目录声明，档位名称不等于具体模型或已知价格。不改写日志或改变宿主计价优先级。

## 步骤
1. 扩展 answer 的响应名称参数；仅两个 Qoder 站点在 ask 中取得当次名称。
2. 添加覆盖两站、全部样例家族、同名槽位、档位、动态名称、刷新失败及 QwenWork 不变的测试。
3. 更新 README 与插件版本 0.2.38。
4. 执行完整 Qoder 测试和插件形状检查，发布关联 #412 的 PR。

## 验证
包测试验证 JSON/SSE、路由与用量保留；本机独立包装实验另有两站非 Kimi 成功样例，但不据此声称所有真实模型均已实测。新列表不可用时仍可能只有别名；价格快照不属于本次范围。
